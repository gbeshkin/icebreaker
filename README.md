# What Do You See?

A team icebreaker where each participant draws an original surreal card.

## Local development

```sh
npm ci
npm run dev
```

The app is available at `http://localhost:3000`.

## Deploy to Railway

This repository includes `railway.toml`; Railway builds the app with `npm run build` and starts it on Railway's assigned port.

1. Push this repository to GitHub.
2. In Railway, create a project and deploy the GitHub repository.
3. Generate a public domain in the web service's Networking tab.
